# Mira desktop 0.6.1-alpha.14

New Mira branding, clearer chat activity, and more consistent computer control.

## Highlights

- **New Mira look:** updated app and channel icons, website-ready branding, and a new illustrated macOS installer.
- **Visible computer work:** CUA control displays a separate Mira agent cursor when the companion supports it.
- **Remember your agent:** new chats restore the last selected external agent and its own model after reopening the app.
- **Quieter tool calls:** compact activity groups, readable tool names, useful input and output, and clear messages when a tool returns no text.

## Fixed

- Auto everything now applies to computer input. Explicit approval and deny rules still take precedence.
- Saved model choices stay scoped to their engine, so provider settings cannot give Codex an incompatible model.
- Intermediate chat messages are grey; final answers retain their emphasis while streaming.
- MCP screenshots and text render directly instead of showing transport JSON or base64 content.

## Notes

The agent cursor requires the companion's visual cursor API. Older companions continue to control the computer and report when the overlay is unavailable. Computer use still requires the relevant macOS permissions.
