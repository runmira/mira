# Mira desktop 0.6.2-alpha.16

A transcript that reads as one column, and a chat that stays where you left it.

## Highlights

- **One straight line.** Tool calls, assistant replies, status notes and the duration chip all start on the same left edge, and their trailing controls share one right rail. The stream no longer steps in and out as rows change kind.
- **Full-contrast agent text.** Running commentary between tool calls is no longer dimmed — if the agent said it, it reads like the final reply.
- **No more scary error when you stop a turn.** Pressing Stop now leaves a quiet "Turn ended manually by user" line instead of a "The request could not finish" card offering to retry a turn you deliberately ended.
- **Scrolling that stays put.** Scrolling down while a reply is streaming no longer yanks the view away mid-read; the transcript yields to your scroll and resumes following when it settles.
- **Line counts on grouped edits.** A run of file edits shows its net `+N −N` on the right of the group header.

## Changed

- Composer image attachments no longer print a filename under the thumbnail. Hover or focus the thumbnail to see the capture's window name, dimensions and any text read off the screen.
- Removed the branch-elbow marker from completed shell commands, so those rows line up with the rest of the stream.
- Follow mode now uses a wider release distance than engage distance, so drifting near the bottom while reading no longer captures the viewport.

## Fixed

- Dragging the right panel's edge, or the terminal panel's splitter, resized nothing and moved the app window instead.
- The divider under a collapsed turn sat flush to the column edge while the rows it separated sat 8px inside it; both now line up.
- A turn stopped by hand is no longer reported as a failed response, and no longer offers "Retry message" or "Connection settings".

## Known issues

- Queueing a message while an external agent is working can fail to show the queued-message card. The message is still accepted and runs when the current turn ends. Being investigated; say so in a report and we'll pick it up from the logs.
