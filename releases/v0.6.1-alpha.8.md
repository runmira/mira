# Mira v0.6.1-alpha.8

Work keeps going without you: queue and steer messages, resume after usage
limits, hand a chat from one agent to another, and let agents run parallel
threads. Codex gets a real plan mode, and the sidebar shows what's waiting
on you.

## Highlights

- **Queue and steer.** Send while a turn runs: messages queue up, and you can edit, reorder or remove them, or steer one into the running turn. The queue survives restarts.
- **Resume after usage limits.** A chat that hits a limit shows when it resets and picks the task back up then — automatically, if you turn that on in Settings.
- **Codex plan mode.** "Plan only" puts Codex in its own plan mode; its plan arrives as Mira's plan card, and approving it starts the build.
- **Hand a chat to another agent.** Switch from Claude Code to Codex (or any agent) and the new one gets what the last one did. The chat marks the handoff with both engines.
- **Agents do more through Mira.** They can launch parallel threads in their own git worktrees, ask you privately for an API key, show a chart or page right in the chat, and drive more of the browser.
- **A sidebar that says what needs you.** Badges on chats waiting for an approval or answer, search, launched threads nested under their chat, worktree branches, date sections, and a new hover card.
- **Quote, ask aside, copy.** Select text in a reply to quote it into your message, ask about it in the side chat, or copy it. Clicking a quote jumps back to the original.

## New

- **Message queue:** messages sent during a turn wait in a queue you can
  edit, reorder and remove from. "Steer" puts one into the current turn.
  Queued messages are saved, so a restart doesn't lose them, and a message
  whose delivery can't be confirmed is held for you to check instead of
  being sent twice.
- **Usage-limit recovery:** when a turn stops on a limit, a card shows when
  it resets with Resume, Schedule and Snooze. Scheduled resumes survive a
  restart.
- **Settings → General → Running sessions:**
  - *Auto resume after a limit resets* schedules the resume for you.
  - *Keep the screen awake while a session runs* stops the Mac (or Linux
    machine) from sleeping while any chat is working.
- **Codex:**
  - Plan mode with Mira's plan card: approve to build, or reject with a
    note to get a revised plan.
  - Questions Codex asks mid-turn can be answered later; answers are saved
    and delivered when Codex is ready.
  - Goals, steering mid-turn, and mode changes that apply from the next
    turn without restarting Codex.
  - Mira's tool guidance now reaches newer Codex models, and Codex is no
    longer shown duplicates of its own file and shell tools.
- **New agent tools:**
  - `thread_launch`, `thread_read`, `thread_wait`, `thread_send`,
    `thread_list`: start separate chats (optionally in their own worktree
    and branch) and check on them. They show in your sidebar; approvals
    they need wait for you.
  - `request_secret`: a private field for an API key or token. The value
    is stored in a file only you can read; the agent gets the path, never
    the value.
  - `html_render`: a self-contained page (chart, table, mockup) shown in
    the chat, sandboxed.
  - Browser: hover, select, upload files, drag, answer dialogs, wait for
    text to appear, and light/dark mode. A page stuck on an `alert()` is
    reported instead of hanging.
- **Agent handoffs:** switching agents passes the previous agent's work to
  the new one, and the divider shows "Context handoff" with both engines'
  icons. After an agent restarts, it's told which of its background work
  was cancelled.
- **Engines:**
  - Changes to `mira.yaml` (new engines, providers or API keys) apply
    without restarting Mira.
  - A second account of a provider, e.g. `anthropic-work` with its own key,
    via `engines:` with `driver: native`.
  - Picking an agent uses its `engines:` settings from `mira.yaml`.
  - Switching models warns when earlier reasoning won't carry over.
- **View changes** on a reply: the diff of exactly what that turn changed,
  kept as it was even after later edits.
- **Sidebar:** search, "waiting on you" badges (also on collapsed folders),
  threads nested under the chat that launched them, worktree branch marks,
  date sections, archived chats that open on click, and a redesigned hover
  card that also works for agent chats.
- **Composer:** drafts kept per chat, quotes as cards, screenshot a region
  of your screen (desktop app), native file and folder dialogs (desktop
  app).
- **Project switcher**, **related chats**, and **keyboard shortcut
  settings**.
- **Usage page:** includes Claude Code and Codex work read from their own
  transcripts, and prices models from a live price table.
- The browser pane opens when an agent starts using the browser.

## Improved

- Long chats load in pages and render only what's on screen, so they stay
  fast; a message that fails to render shows an error card instead of
  blanking the chat.
- Delegated tasks show what the helper is doing, step by step.
- Agents launched by Mira no longer inherit API keys from your shell
  environment; keys come only from the agent's own settings.

## Fixed

- **Archived** showed every open chat as "Untitled · 2961w". It lists only
  archived chats now, with their real titles and ages.
- **Codex ignored Mira's tools and cards:** newer models dropped the
  instructions that described them.
- **MCP servers asking for input through Codex** always failed (Mira
  replied in the wrong format). Forms now show Mira's form card;
  confirmations show the normal approval card.
- **A blue focus ring** appeared on the first item of menus and dialogs
  opened by mouse.
- **The update popup** showed the first 0.6.1 alpha's highlights for every
  later alpha.
- **Agent chats' hover card** said "No messages yet".
