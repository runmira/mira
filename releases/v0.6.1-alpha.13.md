# Mira desktop 0.6.1-alpha.13

## Highlights

- **Computer settings:** use this desktop or pair another Mira computer with a short-lived link. No manual pairing tokens or YAML setup required.
- **Window control:** choose an application window for CUA background input and keep your pointer and focus. Pairing does not enable computer use or approve actions.
- **Chat recovery:** clearer Claude retry handling, quieter external-agent progress, Mira logo loading screens, and improved desktop window dragging.

## Improved

- Computer access can be checked and revoked from Settings. Pairing credentials are scoped to computer control and kept outside browser storage.
- CUA control uses explicit window handles, atomic clicks and drags, verified remote HTTPS, RPC deadlines, and serialized input.
- Unconfirmed input pauses further actions. Cancellation releases held keys and buttons before subsequent input.

## Testing this alpha

Native foreground control needs the operating system's screen recording and accessibility permissions. Background input requires a running CUA companion. Live pairing between two computers and CUA background control need verification on real desktops.
