# Mira desktop 0.6.2-beta.2

The second 0.6.2 beta tidies the sidebar and model picker, makes auto-compaction dependable, and brings native forks, sign-in and rewind to Codex, Claude Code and OpenCode.

## Highlights

- **A calmer sidebar.** Each chat is listed once, in its project. Search and filters sit at the top, with counts for Working and Needs you, and a chat with nothing going on is a single line.
- **Auto-compaction you can trust.** Mira measures the request it's about to send against what the provider actually counts, compacts before the window fills, mid-turn included, and recovers when a provider says a request is too long. Compactions Codex and Claude Code run on their own now appear in the transcript, and the context ring shows where each agent will compact.
- **Fork agent chats.** Fork a Codex, Claude Code or OpenCode chat into a separate chat that keeps its project, engine and model. Codex can fork from any completed turn.
- **Sign in where you work.** OpenCode signs in from Settings in a built-in terminal, Codex signs in and switches accounts in the app, and a chat whose model needs a sign-in says so and links to it.
- **A model picker just for models.** Uninstalled agents and providers without a key stay out of the list, "Default model" names what you'll get, recent picks come first, and switching a chat to another agent asks first.

## Fixed

- Agents that start but can't answer for a model (OpenCode with no provider login) show "Sign-in needed" instead of "Ready".
- A queued message no longer gets stuck as "dispatching" when a direct prompt starts at the same moment.
- Codex model changes show the new model right away and apply on the next turn.
- The picker's session row no longer squeezes its buttons; Compact, Fork and Revert moved to the context meter, `/fork` and `/revert`.

## Under the hood

- Claude Code chats rewind files through Claude's own checkpoints, with a preview, coverage notes and undo.
- Each agent's capabilities are negotiated against the installed CLI version and recorded per launch.
- `auto_compact_after` now reaches Codex and Claude Code. An opt-in acceptance script exercises the real CLIs.
- This beta includes PR #204 and the sidebar cleanup.

## Testing notes

- Frontend (172 tests), external-agent (286), server (282) and harness suites, TypeScript, Clippy and the production build passed.
- Installed OpenCode v2.0.22 passed live forks, steering, cancellation and terminal sign-in. Claude Code and Codex were exercised through protocol tests, not live accounts.
- Full packaged desktop acceptance across authenticated providers remains to be tested.
