# Mira desktop 0.6.2-beta.5

This beta makes code review dependable: draft comments are no longer lost, the uncommitted diff stays current, and the right panel comes back the way you left it.

## Highlights

- **Review drafts are kept until they're sent.** Comments survive switching between turns and closing the Diff tab. If a send is rejected, the draft stays and an error explains what happened. When a file changes after you comment on it, the comment moves to a separate editable section with its original quote, instead of attaching to different code.
- **The uncommitted diff stays current.** It refreshes as agents run tools, when you return to the app, after reconnecting and on a regular poll.
- **The panel layout is restored.** Panel width, open file and tool tabs, the active tab and the selected turn come back per account and working directory. Only paths and a turn number are saved; file contents, prompts, diffs and comments are never stored.
- **Search the Turns menu.** Filter earlier turns by prompt, turn number or file path, and see when each turn happened.

## Changed

- Earlier turns' file diffs are cached for 10 minutes and load at most four at a time, so large turns open without flooding the server. Two turns with identical prompts no longer share cached diffs.
- The remote-control section has its options menu again, with Copy link and Open link.
- The sidebar toolbar has more room next to the macOS traffic lights.

## Testing notes

- All 199 frontend tests passed, including new tests for rejected sends, keeping drafts, layout restore that stores no private data, limited and cached snapshot loading, and stable turn identity. TypeScript, the production build, module-size checks and the 400 kB bundle budget (395.7 kB) passed.
- Rust, desktop and Supabase CI passed. The model-provider check failed because the CI OpenRouter account is out of credits, so it isn't covered in this build.
- Full packaged desktop interaction remains unverified.
