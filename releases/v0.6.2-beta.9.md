# Mira desktop 0.6.2-beta.9

This beta redesigns Usage, improves background chats and delegation, and restores browser tools.

## Highlights

- **Usage by provider.** Compare tokens and estimated cost with daily provider charts, share bars, and breakdowns by model, day, project or session. Filter providers, choose 7, 30 or 90 days, and export CSV.
- **Agent plan limits.** See the latest limits reported by your external agents, including remaining capacity, usage pace and reset countdowns.
- **Background chats wait for you.** Questions, approvals, plans and secret requests stay pending when you switch away. The sidebar shows which chats need you, and waiting cards return when you open them.
- **Linked helper chats.** Delegated tasks run in the background with Open chat and Stop controls. Helpers can work in isolated worktrees, and their questions and results return to the parent chat.
- **Continue after a restart.** Interrupted chats can continue automatically after Mira restarts, with a setting to turn this off.
- **Browser tools restored.** Browser annotations, the agent cursor and browser toolbar are available again.

## Fixed

- Selecting a sidebar chat opens it immediately; Projects stays visible over the desktop sidebar material.
- Composer suggestions load on demand, issue mentions respond faster, and switching chats is distinguished from reconnecting.
- Pending question cards no longer appear as raw JSON after switching chats.
- Ordinary Claude Code tool progress no longer appears as spurious Helper subagents.
- Turn change summaries filter file changes using the chat's own tool activity, reducing attribution of other chats' edits.

## Notes

- Agent plan limits appear after an agent reports them during a turn; the view shows the latest report rather than a live account query.
- Delegation returns a task id immediately by default. Agents can still request blocking behavior with mode: "wait".
- Background requests now wait by default; automatic denial remains available per chat.
