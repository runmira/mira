# Mira desktop 0.6.1-alpha.15

Restore the illustrated macOS installer layout in release builds.

## Highlights

- **Branded installer:** enable Finder customization in CI so the macOS disk image displays Mira's illustrated background and places the app and Applications shortcut around the drag arrow.

## Fixed

- Release packaging no longer skips the configured background, window dimensions, and icon positions because it is running in CI.

## Notes

Includes the branding, computer-control, remembered-agent, and chat activity improvements from alpha.14. Download the new disk image to see the installer change; an in-app update does not display the installer.
