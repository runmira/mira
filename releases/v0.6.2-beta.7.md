# Mira desktop 0.6.2-beta.7

This beta brings the Search & keys redesign and faster pull requests into the desktop release.

## Highlights

- **Search & keys, organised by service.** Web search, GitHub and Slack keys now have their own groups, with clear saved, shell and missing-key states. Edit or remove a key from its row, and open the right service page to get one.
- **Know when GitHub rejects a key.** Mira flags a rejected saved key and tells you when your `gh` login is being used instead. Open Search & keys directly from the notice to replace or remove it.
- **Faster pull requests.** The PR panel, side pane and Work tab share cached PR data. Details start loading on hover or focus, GitHub requests run in parallel, and token checks are remembered.
- **Reload where you left off.** Reloading or completing sign-in keeps the chat and route you were viewing.

## Fixed

- Changes from PRs #217 and #218 had been merged into feature branches and were missing from the released app. They are now integrated into main.
- Guided PR walkthroughs remain available alongside the shared files cache.

Includes changes since 0.6.2-beta.6. Session spend limits (#145) remain separate work and are not included in this release.
