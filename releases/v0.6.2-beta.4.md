# Mira desktop 0.6.2-beta.4

This beta brings guided code review into a resizable Diff tab and keeps the context panel up to date as agents work.

## Highlights

- **Review changes beside the conversation.** View changes opens a Diff tab in the right panel. Keep file tabs alongside it, resize the panel, or expand it for a closer look.
- **Choose the turn to review.** Open the latest turn's saved changes directly, or use the Turns menu to select an earlier turn with edits. Historical snapshots stay available after the agent commits.
- **Walk through a change.** Guided review orders the core change, dependent files and tests, explains each stop, and lets you ask questions and track hunk approvals.
- **Context that stays current.** Changed files and the current branch's pull request refresh while agents work, including external agents, and when you return to the app.

## Changed

- Diff controls use capsule buttons, tooltips and distinct active icons for wrapping and line numbers. Narrow panels use unified diffs; wider panels offer side-by-side review and a file tree.
- Clicking a changed file opens it in its own right-panel tab. Switching tabs preserves the open review and draft comments.
- Both pull-request code views use the shared diff renderer. Review and merge actions wrap cleanly instead of squeezing their labels.
- Thinking transcripts render Markdown, including lists and code blocks.
- Xcode is available in the editor picker when installed on the Mac.
- Remote control keeps its switch without the connected indicator or link.

## Fixed

- macOS traffic lights are positioned natively to align with the sidebar toolbar, including after window resizing.
- Changes discovered through shell commands and generic external-agent tools refresh the context panel.
- Pull-request discovery uses the main PR panel's authentication and reports lookup errors instead of silently showing no PR.
- Historical turn reviews handle binary files and unavailable snapshots without preventing the remaining files from opening.

## Testing notes

- All 195 frontend tests passed, including source-menu selection, repeated prompts, resize behavior and toggle states. TypeScript, the production frontend build and module-size checks passed.
- Desktop compilation and an isolated AppKit geometry probe passed; the probe checked initial alignment, repeated positioning and resizing.
- Browser fixtures covered narrow panels and light/dark states. Full packaged desktop interaction, fullscreen transitions and live model-provider integration remain unverified.
