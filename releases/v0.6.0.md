# Mira v0.6.0

The agents release. Claude Code and Codex now run inside Mira next to your
providers, your old chats come with you, Mira ships its own browser, and
the desktop app signs, notarizes and updates itself — on stable, beta or
alpha.

## Highlights

- **External agents.** Drive Claude Code or Codex from Mira on your own plan, next to providers, and switch per chat.
- **Bring your chats.** Import Claude Code and Codex history by project; the next message continues the original session.
- **A new first run.** Onboarding sets up agents or a provider and brings your chats over, step by step.
- **Mira's own browser.** A managed Chromium for the browser tool and the live browser pane, shared with agents.
- **Checkpoints.** Every message snapshots your files; "Restore files" puts them back, and the restore can be undone.
- **Context inspector.** See what fills the context window, drop large tool results, or compact on demand.
- **Rich replies.** PR and issue chips, commit cards, file links that open at the line, diffs you can apply, callouts and sortable tables.
- **Desktop updates.** Signed and notarized builds on stable, beta and alpha, with in-app updates like this one.

## New

### External agents and subagents
- **External agents.** Claude Code and Codex drive the chat with their own
  tools, signed in to your account, with instant switching, agent session
  titles in the sidebar and one approval card for every engine. Shell
  approvals split compound commands; every part must be allowed.
- **Subagents with faces.** Scout, Iris, Atlas, Bolt, Quill and Sentry take
  focused jobs; customise, add, disable or reset them in Settings.
- **Second opinion.** After an external agent edits files, Mira offers a
  review by its reviewer subagent.
- **Agent stats.** External agents' replies show time, tokens and cost on
  hover, live and after a reload; Claude Code and Codex spend counts on the
  Usage page.

### Bring your chats
- **Import from Claude Code and Codex.** Mira finds your history on this
  computer, groups it by repository, and pre-selects recent real work
  (scripted runs are hidden). Imported chats replay readably and open on
  the same agent — your next message resumes the original session.
- Available in onboarding, Settings → External agents, and ⌘K → "Import
  chats".

### Onboarding
- **A redesigned first run**, from workspace to "You're all set": choose
  external agents and/or a provider (kept clearly apart: your plan vs your
  API key), bring your chats, and learn the three things worth knowing.
- Drawn on its own stage, so it reads cleanly over the desktop app's
  translucent window.

### Browser
- **Mira manages its own Chromium** (Chrome for Testing), so the browser
  tool no longer depends on whatever browser is installed. The desktop app
  fetches it in the background on first launch, keeping the download small;
  it updates weekly and falls back to an installed browser if needed.
- **One shared browser** for Mira and its agents, with a live pane that
  fills the panel, shows the site's favicon, and opens when browsing starts.

### Chats
- **Checkpoints and restore.** Before every message the working tree is
  snapshotted (your git index is never touched). Restore previews, then
  reverts edits, removes new files and recreates deleted ones; it can be
  undone.
- **Every changed file counted.** A chat's changes now include edits by
  external agents, shell commands, formatters and deletions — not only
  Mira's own edit tools. Commit only the chat's files.
- **Context window inspector.** A breakdown of the window by system prompt,
  tools, memory and skills, conversation and tool results, calibrated to
  the provider's own counts. Drop a large result, or compact with a focus
  note. Claude Code chats get the same breakdown from Claude Code itself.
- **Usage ring** under the composer, for providers and agents, with the
  context split into the inspector's colours.
- **Rich formatting.** PR/issue chips with hover cards, commit hover cards,
  file references that open at their line, symbol lookups, link previews,
  colour swatches, key caps, applyable ```diff blocks, callouts, sortable
  tables with CSV copy, and folded long logs.
- **Message actions.** Copy, edit & resend, retry, and "Jump to latest".
- **Images.** Paste or drop screenshots into the composer.
- **Review changes.** A drawer with per-file diffs, revert, and line
  comments sent to the agent.
- **Thinking** shows as a collapsible section; reply stats (time, tokens,
  cost) survive a reload.

### Workspace
- **⌘K command palette** for actions, settings and recent chats.
- **Integrated terminal** (⌘J) with real shells, plus a read-only Agent tab
  mirroring the agent's commands.
- **Usage and cost dashboard** in Settings → Usage: by day, model and
  project, with CSV export.
- **Notifications** when a chat finishes, needs approval or asks a
  question; unread dots for chats that finished in the background.
- **Headless mode:** `mira -p "task"` runs one task and exits.
- **Model routing:** a `small_model` for background work.
- **Hooks:** SubagentStop, Notification, PreCompact, SessionEnd and prompt
  hooks, and Settings → Hooks to set them up in plain English.
- **Rate limits** from the provider's response headers.
- **`mira eval swebench`** runs Mira on SWE-bench and scores it.

### Desktop app
- **Release channels.** Mira, Mira Beta and Mira Alpha install side by side,
  each with its own icon, sign-in and update feed.
- **Signed, notarized and self-updating.** A green button in the toolbar
  says when a new build is out; "Update now" installs it and restarts.
- **New icon.**

## Changed
- Compaction is rare, whole-conversation, and shown once.
- "External agents" and "Subagents" are now the names for the two kinds of
  agents.
- Code blocks get line numbers and fold past 30 lines; streamed text
  arrives smoothly.

## Fixed
- Files mentioned with a line (`src/lib.rs:42`) opened with "file not
  found".
- A restarted server could drop you into another conversation on reconnect.
- A finished turn could leave an approval card nobody could answer.
- Plugin hooks that failed on every message.
- The browser pane saying "Starting the browser…" forever with a headless
  browser.
- Live tests started real Claude Code sessions on every test run.
