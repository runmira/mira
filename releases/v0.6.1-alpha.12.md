# Mira desktop 0.6.1-alpha.12

This alpha improves Claude Code response handling, cancellation, and conversation recovery.

## Highlights

- **Messages keep moving.** Slow file checkpoints are skipped after five seconds, and agent startup has a clear timeout instead of leaving the chat waiting indefinitely.
- **Stop closes Claude.** Mira closes the Claude process and its background commands, then resumes the conversation when you send the next message.
- **Clearer progress and errors.** See preparation, Claude queue/start acknowledgements when available, retry delays, and specific failure reasons.
- **Reliable settings and history.** Model and permission changes wait for confirmation. Settings chosen after Stop apply on resume, and questions and answers keep their order after reload.

## Fixed

- Stop and approval commands can get through while a message is preparing.
- Closely spaced prompts cannot start overlapping foreground turns.
- Background, cancelled, and duplicate results cannot finish a different prompt on CLIs that identify their originating input.
- Interrupted protocol writes cannot corrupt later messages or approvals.
- Late settings confirmations cannot overwrite a replacement agent’s choices.
- Slow transcript writes do not block capturing subsequent conversation frames.

Claude’s own network, service, and model response time can still vary. This release bounds Mira’s checkpoint preparation and startup, and exposes Claude retry activity when the CLI reports it.

## Download

macOS on Apple Silicon. The release workflow signs and notarizes the app and updates the alpha channel’s in-app update feed.
