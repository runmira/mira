# Mira desktop 0.6.2-beta.3

The third 0.6.2 beta gives the window a proper Mac toolbar, brings back Recents, carries context across engine switches, and makes long chats compact with less lost and less waiting.

## Highlights

- **A Mac toolbar.** The sidebar toggle, New thread and Search sit beside the traffic lights in every view, Settings included. Hide the sidebar and the chat curves around them; every page shares one toolbar, level with the lights.
- **Recents are back.** The chats you touched last, across every project, at the top of the sidebar, each naming its project.
- **Switch engines without losing the thread.** Moving a chat to another engine hands over its messages, commands, edits and plans, sized to the new engine's window, and the agent can read anything that didn't fit.
- **Mention issues with `#`.** Type `#` in the composer to pick an issue or PR from the chat's repo; it becomes a chip that links to GitHub.
- **Compaction that keeps more.** Long chats keep their recent turns whole, use OpenAI's and Anthropic's own compaction where available, and prepare the next summary in the background instead of pausing you.

## Changed

- The project switcher opens next to what you clicked (the new chat's project name, or the composer's folder chip), with each project's chats and last activity.
- In fullscreen the toolbar moves to the window's edge, since macOS hides the traffic lights there.
- The window can't be made narrower than 800px, and the desktop app no longer switches to the phone layout.
- `/remote control on|off` and a switch in the context panel turn remote access on and off; while it's on, the panel offers Copy link and Open link.
- Resuming a Claude Code chat that's near its limit asks whether to compact first.

## Fixed

- Codex edits show their files and changes, and chats started in a parent folder track changes in the repositories they actually touched.
- Quick edits of the same size are no longer missed in change counts, and a turn's diff survives the agent committing it.
- Commit and branch links in the transcript resolve in child repositories, and a rejected GitHub CLI login recovers in the PR panel.

## Under the hood

- This beta includes PRs #207, #208, #209 and #210.
- `MIRA_HANDOFF_TOKENS` raises the handoff budget (default 16k tokens, up to 64k).

## Testing notes

- Frontend (183 tests), server (298) and the PRs' own suites, TypeScript, Clippy and the production build passed on their PRs.
- The new toolbar was checked in a browser harness that mimics the Mac window; this beta is the first packaged build of it. The traffic lights' new position and the notch need a look on a real Mac.
- Live native API compaction and a paired-device remote-access round trip have not been exercised end to end.
