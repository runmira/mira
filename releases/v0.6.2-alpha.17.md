# Mira desktop 0.6.2-alpha.17

Fixes queueing a message while an external agent is working, plus two
alignment corrections in the tool stream.

## Highlights

- **Queueing mid-turn works again.** Sending a message while an agent is busy — opencode, codex, claude-code — now delivers it after the current turn instead of stalling.

## Fixed

- Queued messages were stamped with a **globally** selected engine rather than the engine a given chat is actually running. A session that started on a provider and later switched to an external agent kept the provider's name forever, so its queued messages failed their own dispatch check.
- One unsendable queued message no longer stalls every message queued behind it. The queue worker used to exit on the first failure and only restarted when something else woke it.
- Steering a queued message hit the same faulty check, so steering was refused on any chat that had switched engines.
- The thought cell was double-padded (8px of gutter on top of the block's own 8px), putting it 16px in from every other row.
- The action verb is now a fixed-width column. Tool filenames previously started at a different offset per row, and slid sideways mid-turn as the verb changed (`Read` → `Reading` → `Edited`).

## Known issues

- None outstanding.
