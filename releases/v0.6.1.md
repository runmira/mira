# Mira v0.6.1

New windows beside the chat, light mode, forking, and a long list of
fixes for agents and the composer. Ask a question while the agent works,
watch its dev servers, run your tests, preview on phone and tablet sizes,
and branch a chat from any message.

## Highlights

- **Ask aside.** Ask a quick question about the chat while the agent keeps working — it answers from the conversation (and any `@files` you name) without interrupting or adding to the chat.
- **New windows:** Processes (dev servers, ports, logs, stop/restart), Tests (run, see each failure, "Fix this"), Activity (what each message changed, with restore) and Device preview (your app at phone, tablet and laptop sizes).
- **Fork from here.** Branch any chat at a message into a new chat; forks sit under the original in the sidebar.
- **Appearance.** Light and dark themes, accent colors, interface size, and diff settings — the terminal, diffs and whiteboard follow along.
- **Agents get Mira's tools.** OpenCode and other ACP agents can now drive Mira's browser (the one in the pane) and run background processes that show in the Processes window — Claude Code gets the processes too.
- **OpenCode asks properly.** Its questions, plan prompts and approvals now show Mira's cards instead of being dismissed.
- **A Stop that stops.** The composer no longer spins after you stop a turn, and shows Stop when you come back to a chat that's still working.

## New

- **Ask aside** window: a side thread per chat, answered by the chat's
  model with no tools. "Send to agent" puts an answer in the chat box.
- **Processes** window: everything the agent started in the background,
  the ports each process listens on, live logs, Stop / Restart, "Send logs
  to agent", and a field to start a command yourself. Other listening ports
  are listed too (installed apps hidden by default).
- **Tests** window: detects the project's test command (cargo, npm / pnpm
  / yarn / bun, pytest, go, rspec…), streams the run with live counts, and
  lists each failure (cargo, Vitest, Jest, pytest, Go) with a "Fix this"
  that drafts the prompt for you.
- **Activity** window: one card per message — files changed with line
  counts, commands run — with "Jump to message" and "Restore to before".
- **Device preview** window: one page in several sizes side by side;
  "Preview" on a dev server in Processes opens it there.
- **Fork from here** on your messages: a new chat with everything through
  that reply. Mira's own chats for now; agent chats are next.
- **Appearance settings:** theme (system / light / dark), accent color,
  interface size, diff layout, highlights, markers and wrapping, and a
  turn-finished sound you can turn off.
- **Tooltips** on every message and tool-card button, with shortcuts.

## Fixed

- **OpenCode** questions were auto-dismissed ("The user dismissed this
  question") and edits/commands never asked for approval. Mira now takes
  its questions on the question card and launches it with ask-first rules.
- **Signed-out Claude Code** showed as ready with no account; it now says
  it isn't signed in and offers `claude auth login`.
- **Onboarding** could sit on "Checking…" forever while agents were
  probed; each agent now shows as soon as it's checked, with Check again.
- **Silent agents:** a warning after 45 s with no response, and a crashing
  agent's own error instead of "stdin closed".
- **Stop** left the composer spinning, and reopening a running chat showed
  no Stop button.
- **"Working… 0s"** stayed at 0s while the turn ran.
- **Whiteboard** strokes landed above the pointer on Retina screens, and
  the board ignored light mode.
- **File viewer** refused files over 200 KB; it now opens files up to 2 MB.
- **Browser pane** sent every page to the agent browser even when it could
  be shown in the pane.
- **Questions answered in another window** stayed open in this one.
- The environment picker said "Code Sandbox"; it's **Cloud Sandbox**.
- **Light mode:** question and plan cards hid the selected option's mark
  and description, and tooltips stayed dark.
- **Agent approvals** showed the request's raw JSON (tool-call ids,
  option kinds). They now show the action: the command for a shell call,
  a diff for an edit.
- **No sound** played when an external agent finished a turn.
- **A model's malformed tool call** (e.g. OpenCode's "tool call delta is
  missing id or name") now reads as what it is, with what to do, instead
  of a raw internal error.

## Earlier in 0.6.1

- **No more silent stops.** When a model writes a tool call as text
  (`<tool_call>…`, `<function_call>…`) instead of calling the tool, Mira
  asks it to make the real call — up to twice a turn.
- **Smarter shell hints.** A `bash` command that fails on a missing path
  suggests the `glob` and `grep` tools.
