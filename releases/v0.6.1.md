# Mira v0.6.1

Fewer turns that end for no reason. When a model writes a tool call as text
instead of making it, Mira now notices and asks it to make the call; and a
shell command that hits a missing path points the model at the right tool.

## Highlights

- **No more silent stops.** When a model writes a tool call as text (`<tool_call>…`, `<function_call>…`) instead of calling the tool, Mira asks it to make the real call — up to twice a turn — instead of ending the turn.
- **Smarter shell hints.** A `bash` command that fails on a missing path suggests the `glob` and `grep` tools, so the model stops retrying the same broken command.

## Fixed

- **Near-miss tool calls.** Some models drift to tool-call markup in their
  text or reasoning (`<dots_function_call>cd … && grep …</dots_function_call>`),
  which executes nothing and used to end the turn as if it were done. Only
  the markup counts, so replies that merely talk about tool calls or
  `function_call` fields are left alone.
- **Shell retry loops.** `bash` failures with "No such file or directory"
  now carry a hint toward `glob`/`grep` (a `crates//Cargo.toml` typo or a
  missing `*` is the usual cause), and the tool's description prefers the
  dedicated search tools over `bash` + `grep` pipelines.
